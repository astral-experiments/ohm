# Benchmark reproduction inputs

These files preserve the workloads and measurement code that accompanied earlier Ohm benchmarks. Directories follow the Ohm release number. The APFS directories contain the original macOS measurement drivers and allocation checks. The formatter directory contains the frozen edit protocol, paired timing driver, host checks, and statistical analysis. The 1.99.0-6 comparisons retain the ready-tests and overlap measurements. Historical drivers use the paths and toolchain versions of their original campaigns.

The standard runners, release manifests, and replay fixtures live in the [Ohm repository](https://github.com/astral-sh/ohm). The [1.98.1-2](https://github.com/astral-sh/ohm/tree/20ed3ca3e608d46be4468ddb4459c1ec0690b9a0/scripts), [1.99.0-1](https://github.com/astral-sh/ohm/tree/a7241802952abf7c827aee2099bb672875f91ed3/scripts), [1.99.0-2](https://github.com/astral-sh/ohm/tree/ab28c851c83279a62147cf628ceff596c169e0b9/scripts), [1.99.0-3](https://github.com/astral-sh/ohm/tree/dc667df161f6cb743a074f718d23f53e88e15106/scripts), [1.99.0-5](https://github.com/astral-sh/ohm/tree/9cbebcf02df6036feaea17cf16173c01185c856e/scripts), [1.99.0-6](https://github.com/astral-sh/ohm/tree/04c83d53483607aec4f93fd2bb55b412f101d677/scripts), and [1.99.0-7](https://github.com/astral-sh/ohm/tree/fe39ea0b92460919ceee0b6d886d747c4cc0dc5d/scripts) trees retain the checked-in reports and sources for those studies.
