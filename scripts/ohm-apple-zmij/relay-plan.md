# Experimental native rechecks for the build-script compiler

This is an isolated correctness and work-count experiment on native Apple silicon. The product baseline is unmodified Cargo #293 735e1528ed741015c57676dccf05dbdc0ff7bed1. The second Cargo is an unpushed detached commit 6b2d0f6c1a23c862d5373d0bce03db5d889dd042, full tree 71a66ff87b11d3c7584883a5589099a2f2957a46, patch SHA-256 2d4ffa3b8fb6e31e57600ad801b0bf80faa19aba01efe0ef903bda1f1ea1298c. Its only source change admits custom-build compilation to the existing receipt path when the actual native driver supports the host, no explicit relink override is present and normal collection is enabled. It changes no build-script execution, fingerprint comparison, linker or receipt algorithms. The candidate adds ordinary recipe collection for this class of host build scripts even where no inherited native inputs are found. This experiment does not establish correctness for all custom-build graphs, flags, alternate linkers, compiler wrappers or arbitrary build scripts observing their own compiler command.

The access-restricted packaging repository transports the exact patch and original commit object as one SHA-256-pinned event input. It can be read by workflow jobs, integrations and authorized readers of any emitted evidence. Treat the code as visible to repository readers. The inputs contain no credentials. Only the QA launcher, digest and fixture are on a packaging QA ref. There is no remote Cargo branch for the experiment. Both original Rust SDKs and Cargo 735e1528 are reconstructed with their full authenticated source trees using the same production bootstrap from previous native qualification. The actual compared Rust compiler in both installations is fixed at 82911b516fb35608fd70ada4deb6f8429277f410. Both Cargos are optimized native builds with all-static and ohm-defaults from the same signed builder, lockfile and ordinary APFS, with no distribution PGO. No timings are collected for an effect estimate.

The carried original CRC provider fixture runs 196 genuine warm/independently empty commands in each Cargo installation, covering direct and transitive placements, declared and unwatched archives, defaults on/off, real Rust edits, missing, malformed, repair and same-inode, same-size, same-mtime replacements. The separate hard marker bundled archive checks remain. Deliberately undeclared defaults-off differences are recorded separately.

A new build script consumes two ordered search paths inherited from an actual CRC build dependency and calls a C function in the selected archive. It writes the value and its own Rust code constant, a tracked environment variable and a tracked directory sum into generated Rust. The final native program prints all four values. Compare 16 warm and independently empty cases per Cargo. Keep two genuine fresh controls, the higher archive and repeat, environment change, directory insert/update/remove, real build.rs edit, E0425 and recovery, malformed/missing native archive and recovery. The raw native rechecks, script executable hash and real script execution must be distinguished. Store all original event streams including every Xcode invocation, Cargo streams, generated source and full programs. A returned executable must match its own independently empty image byte for byte. Any controlled native, environment, directory, source addition or invalid outcome that disagrees with clean rejects the experiment.

Finally run the actual Ruff #29042 typeshed test build with exact Cargo +ohm and one checked-out branch, old and new empty references, cold, edit, two unchanged repeats, invalid Rust and repair. Require both native tests, exact 819-member ZIP, its three changed stub bodies and complete same-role verified Mach-O. Preserve complete cross-Cargo programs and the native checksum basis without assuming identical Cargo artifact directories. Reopen the exact original stock-link and rustc argv, build-script program runs, output inode and mtime. The proposed cascade cure requires the experimental arm to avoid rerunning the build script and full final compilation on both unchanged commands while still rejecting every real unsafe input. Avoiding only the script compiler or Xcode link is a separately reportable and insufficient result. Keep raw baseline and candidate observations wherever an acceptance gate is missed.

The independent timing study at 41071825672 uses unmodified 735e1528 exclusively for both Rust roles. This experiment contributes no observations to that comparison.
