# Ohm 1.99.0-22 on Linux

The Linux benchmarks compare Ohm 1.99.0-22 and stock Rust 1.99.0 on dedicated machines for uv, Codex, Ruff, and ty.

[Release](https://github.com/astral-experiments/ohm/releases/tag/ohm-1.99.0-22) · [Optimizations guide](../../docs/optimizations.md)

## Published toolchain

The table shows mean elapsed time on Linux across two replays per toolchain for Ruff, uv, and Codex, and four for ty. The total sums the four means before rounding.

| Session           | Rust 1.99.0 | Ohm 1.99.0-22 | Time saved |
| ----------------- | ----------: | ------------: | ---------: |
| Ruff              |    679.99 s |      362.93 s |     46.63% |
| uv                |    173.28 s |       98.90 s |     42.93% |
| Codex             |    617.74 s |    1,075.88 s |    -74.17% |
| ty                |    352.43 s |      204.92 s |     41.85% |
| All four sessions |  1,823.43 s |    1,742.64 s |      4.43% |

The four focused Codex rendering test commands each took 90.56–95.48 s with Ohm and 2.83–3.13 s with stock across the two replays. Both toolchains started 3,439 tests at the final TUI step in each replay. [Per-command timings](1.99.0-22/sessions.json)
