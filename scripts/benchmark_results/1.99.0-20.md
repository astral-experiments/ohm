# Ohm 1.99.0-20 on Linux

## Native links in Ruff

We built the Ruff CLI and its integration test with the Cargo and rustc revisions pinned for
1.99.0-20. Three consecutive unchanged builds invoked zero compilers and zero linkers, and all
97 integration tests passed. We then had Ruff's build script declare a static library. Changing
the library relinked both executables. Restoring it reproduced both original binaries byte for
byte. Each subsequent unchanged build invoked zero compilers and zero linkers.
[Release qualification](https://github.com/astral-experiments/ohm/pull/206)

## Cargo source measurements

These experiments compared individual Cargo changes with their respective parents on Ruff.

- After an inactive profile edit, a fresh source build of Cargo cut the package build from
  186.56 to 65.50 ms and the serde test build from 199.26 to 75.42 ms. On a larger parser
  workload, the edit and the following build together took 21.91% less time, but the first
  unchanged build after restoring the manifest took 3.75% longer.
  [Package and serde timings](https://github.com/astral-experiments/ohm-cargo/tree/b6cac8480b9876a57f60dbeb91befc36c1e36a1d/benchmarks/ruff-dev-loop-20261027/rc20-profile-workspace-resolve-local-source-build) · [Parser timings](https://github.com/astral-experiments/ohm-cargo/tree/fc37e69b3941346e4399a6e4151c993c018bf376/benchmarks/ruff-dev-loop-20261027/rc20-profile-only-resolver-h7-results)
- After a lint edit, the serde test build and its first repeat took 18.42% less time in an
  independent run with the released -18 compiler. The change won all 32 pairs. The 95% interval
  was 17.88–19.45%. [Paired timings](https://github.com/astral-experiments/ohm-cargo/tree/c78d1076a768ca9f5f575b6cf48f611c0f87f1bf/benchmarks/ruff-dev-loop-20261027/rc20-active-lint-serde-local-wall)
- Reusing the lockfile encoding after a dependency edit reduced Cargo's instruction count by
  7.77%. The paired wall-time reduction for the edit and its first repeat was 1.90%, with a 95%
  interval from −1.06% to +4.50%. [Instruction counts](https://github.com/astral-experiments/ohm-cargo/tree/6024d099bb66727ab31f89a78d2fba47aa9843fb/benchmarks/ruff-dev-loop-20261027/rc20-workspace-lockfile-serialization-salsa-instructions) · [Paired wall times](https://github.com/astral-experiments/ohm-cargo/tree/08ae6f086d3847f5acd19196c2072a89a4124a7c/benchmarks/ruff-dev-loop-20261027/rc20-workspace-lockfile-serialization-salsa-wall)
