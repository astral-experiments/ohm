# Correctness and provenance

The candidate keeps compact objects in ordinary, self-contained `ar` archives with raw embedded metadata. Cargo's `-Zohm-compact-artifacts=yes` is explicitly opt-in and selects the matching bundled Wild on native `x86_64-unknown-linux-gnu`. Ordinary consumers and exported static libraries receive materialized ELF objects. The current compiler removes the external-store and metadata-compression experiments; their earlier source revisions and receipts remain available as historical comparisons.
