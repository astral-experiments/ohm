# Ohm 1.99.0-18 source studies

## Compiling Ruff integration tests

After a test-source edit in Ruff, a full workspace test build took a median of 12.60 seconds with the earlier scheduler and 11.16 seconds with the change in -18. Cargo used to start a speculative integration-test build even when its library had already finished. Using the available library eliminated one redundant rustc invocation and one link. The change won 22 of 24 paired builds. The paired time reduction was 10.1% (95% interval 8.0–12.3%). These runs isolated the scheduler change on a corrected Cargo source build. [Cargo #260](https://github.com/astral-sh/ohm-cargo/pull/260)

## Checking an already-built Codex workspace

Codex has 165 workspace members and no exclusions. Cargo used to scan all 165 every time it checked whether a path was excluded. The new lookup examines explicit members only if an exclusion matches. [Cargo #263](https://github.com/astral-sh/ohm-cargo/pull/263)

| Warm command                        | Reduction in Cargo instructions |
| ----------------------------------- | ------------------------------: |
| `cargo check --workspace`           |                           7.38% |
| `cargo check -p codex-utils-string` |                          16.80% |

Cachegrind counted instructions in the source-built Cargo process over 12 balanced pairs per command. All artifacts stayed fresh. Path length and registry trust settings affect the result. [Paired measurements and controls](https://github.com/astral-sh/ohm-cargo/pull/263)

## Reading the uv feature comparison

The Linux replays use the same flag combinations as earlier releases. In -18, rustc runs native derives and attributes every time it compiles their consumer. The default and explicit `-Zcache-proc-macros=no` therefore use the same expansion policy. Differences between those two timings measure run-to-run variation. [Rust #244](https://github.com/astral-sh/ohm-rust/pull/244)
