# Ohm 1.99.0-21 on Linux

## Compiler qualification

A 13-byte edit to uv's version parser moved 91 unchanged Clap derives. We applied the same edit
to a warm tree in each run and alternated the three compilers across 12 paired blocks. The parent
and candidate were built from source with the same settings and differ only in how rustc identifies
derive expansions. The last column gives the median for the distributed 1.99.0-20 compiler.

| Command                      | Source parent | Source candidate | Candidate wins | Published 1.99.0-20 |
| ---------------------------- | ------------: | ---------------: | -------------: | ------------------: |
| `cargo check -p uv-cli`      |       12.53 s |          12.04 s |          11/12 |              8.85 s |
| `cargo check -p uv --bin uv` |        3.12 s |           3.09 s |           8/12 |              2.14 s |

All three compilers used the same signed 1.99.0-20 Cargo, and all timed checks were incremental.
[uv edit](https://github.com/astral-sh/uv/pull/21076) · [Compiler change](https://github.com/astral-experiments/ohm-rust/pull/278) · [Comparison](https://github.com/astral-experiments/ohm-rust/actions/runs/41084366039)

## Published toolchain

We replayed the Ruff and uv development sessions twice per toolchain on Linux and the ty session four times. The table gives the mean elapsed time for each. Codex is still running its separate developer workflows.

| Session | Rust 1.99.0 | Ohm 1.99.0-21 | Time saved |
| ------- | ----------: | ------------: | ---------: |
| Ruff    |    524.90 s |      300.64 s |     42.72% |
| uv      |    173.45 s |       99.81 s |     42.46% |
| ty      |    363.95 s |      224.32 s |     38.36% |

All five uv developer workflows were faster with Ohm. After a uv dependency edit, the downstream test took 3.07 s with Ohm and 25.15 s with stock Rust. Ruff's focused test after an edit took 17.75 s with Ohm and 16.94 s with stock Rust. These are medians of four runs per toolchain.
