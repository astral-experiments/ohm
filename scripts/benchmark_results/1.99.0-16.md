# Ohm 1.99.0-16 benchmark results

## Cargo source comparisons

On an unchanged Ruff workspace, recording the inputs observed by a procedural macro eliminated 50
native links from `cargo test --no-run`. Its median fell from 6.088 s to 0.956 s across 12 pairs.
An unchanged `cargo build` had already avoided those links with both versions. Its medians were
0.644 s and 0.641 s, and only four of the 12 pairs were faster.
[Matched Ruff runs](https://github.com/astral-sh/ohm-cargo/tree/d2fae69374cda17ef47ef198a75fdd24d690b34f/benchmarks/ruff-dev-loop-20261027/whole-ruff-cargo-observer-fifo)

A seven-package fixture measured the cost when a macro's input actually changed. Unchanged builds
fell from 190.2 ms to 98.3 ms. Moving the observed token by one byte increased the median from
345.7 ms to 484.8 ms. The resulting binaries matched the clean build after each edit.
[Paired measurements and output checks](https://github.com/astral-sh/ohm-cargo/tree/0c7fdaea22df8b42e67c1ccb6e12b92886c6cb2f/benchmarks/ruff-dev-loop-20261027/observer-fifo-seven-package-results)

Both studies compared the Cargo change with its parent using the same Ohm compiler. The Linux
release benchmarks compare the published toolchain with stock Rust 1.99.0.
