All eight ordinary `cargo check -p uv-client --locked --offline -j8` pairs favor the callable compiler in each marginal study. Even the elapsed time Cargo printed inside the control process exceeded the outer elapsed time enclosing the entire treatment process in every pair. The cumulative compiler stack also passes this directional check in all eight pairs and falls short of 2× in all eight. The studies used the same landed uv edit and the same signed −22 Cargo. All 48 native visits called Cargo directly, with stdout and stderr directed to files. The outer Python clock starts before process launch and stops after `subprocess.run(..., timeout=1500)` returns. These workers ran CPython 3.12.3 on Linux. Its POSIX timeout path polls `waitpid` with sleeps up to 50 ms. The cumulative treatment’s eight external readings cluster between 1,265.45 and 1,265.68 ms, while Cargo reported 1.21–1.23 s. Reducing every control’s outer time by 50 ms while leaving every treatment untouched still gives eight positive pairs per study. The smallest remaining margin is 100.21 ms in stage1 and 49.89 ms in production. A scheduled sleep can overrun, so the table uses the interval argument below, which does not require a limit on scheduler delay. [Hosted timing code](https://github.com/astral-experiments/ohm/blob/125cef4f90f572d8a8d19da42b0bc2b1fcae87a8/scripts/handwritten-panel/run.py#L9-L18) · [CPython timeout behavior](https://docs.python.org/3.12/library/subprocess.html#subprocess.Popen.wait)

Denote one visit’s Cargo display by `C` and its enclosing elapsed time by `E`. Signed Cargo takes its timestamp inside the invocation and floors durations below 60 s to the previous 10 ms. Its internal interval therefore lies in `[C, C + 10 ms)`, and the full Cargo process fits in `[C, E]`. For control `a` and treatment `b`, the full-process speedup is bounded by `C_a / E_b` and `E_a / C_b`. Taking medians of the eight paired lower and upper endpoints gives the bounds above. This recovers the direction for every individual pair without assuming a precise exit timestamp.
