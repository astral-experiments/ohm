# Ohm 1.100.0-1 benchmarks

The four editing sessions took 38.06% less time with the released Ohm SDK. Their mean wall times add up to 1,306.92 seconds with stock Rust 1.100.0 and 809.47 seconds with Ohm. Each project ran both toolchains on the same x86-64 Linux host with the same source revisions, jobs and tests. [Released SDK](https://github.com/astral-experiments/ohm/releases/tag/ohm-1.100.0-1)

## Editing sessions

| Project | Pairs | Stock Rust 1.100.0 | Ohm 1.100.0-1 | Paired speedup | 95% interval |
| ------- | ----: | -----------------: | ------------: | -------------: | -----------: |
| uv      |     2 |           129.55 s |       75.44 s |          1.72× |   1.57–1.88× |
| Ruff    |     2 |           401.82 s |      228.61 s |          1.76× |   1.37–2.25× |
| Codex   |     2 |           485.10 s |      322.81 s |          1.50× |   1.28–1.77× |
| ty      |     4 |           290.45 s |      182.60 s |          1.59× |   1.46–1.74× |

Times are arithmetic means. Speedup is the geometric mean of the within-pair ratios. The earlier campaign saved 48.33% across the same four projects with its own Rust 1.99 baseline and fixtures. [Previous campaign](https://github.com/astral-experiments/ohm/pull/378)

## Comparisons with Ohm 1.99.0-34

Each row covers four paired runs on the original project host. Positive differences mean 1.100.0-1 took longer. The two-sided 95% intervals use the paired differences.

| Workload                                                                            | Ohm 1.99.0-34 | Ohm 1.100.0-1 | Mean change | 95% interval for change |
| ----------------------------------------------------------------------------------- | ------------: | ------------: | ----------: | ----------------------: |
| uv editing replay · Run local-mock-index installation integration test              |       38.04 s |       41.13 s |     +3.09 s |        +1.71 to +4.47 s |
| ty editing replay · Run all semantic package tests                                  |       48.41 s |       51.99 s |     +3.58 s |        -0.39 to +7.55 s |
| ty editing replay · Run Clippy for all semantic targets and features                |       26.13 s |       30.45 s |     +4.33 s |        +2.13 to +6.52 s |
| Ruff developer workflow · edit-check-test-check                                     |       21.59 s |       25.69 s |     +4.10 s |        -0.39 to +8.59 s |
| Ruff editing replay · Run final strict Clippy for both affected packages            |       15.29 s |       17.22 s |     +1.93 s |        -0.26 to +4.11 s |
| Ruff historical replay · Run strict Clippy for the changed core and semantic crates |       19.67 s |       20.25 s |     +0.58 s |        -1.05 to +2.20 s |

The uv comparison used the same import-level Clippy allowance in both SDKs. Both Ruff SDKs ran Clippy with `-D warnings`. The 1.99 commands omit the allowance for `clippy::needless_nonzero_get`, a lint introduced after that release.

All 216 individual-command samples, Ruff doctests and ty worktree startup on ext4 and Btrfs are complete. The Codex developer workflows and direct SDK comparisons are still running.
