# Ohm 1.100.0-1 benchmarks

We measured the published Ohm 1.100.0-1 and stock Rust 1.100.0 on four x86-64 Linux hosts. Each project ran both toolchains on the same machine, with its source revision, job count and test selection held fixed. The four recorded sessions totaled 1,306.92 s with Rust and 809.47 s with Ohm, using the mean for each project. [Release](https://github.com/astral-experiments/ohm/releases/tag/ohm-1.100.0-1) · [Installed SDK and host records](workflow-build.json)

## Comparisons with the previous release

The four editing-session means in the 1.99.0-34 campaign totaled 1,477.50 s with stock Rust and 763.44 s with Ohm. Ohm took 48.33% less time in that campaign and 38.06% less time in this one. The stock compiler and the fixtures changed between campaigns. [Previous measurements](https://github.com/astral-experiments/ohm/tree/1c818c3ca4e8fd95652222ee6b7540266633c176/scripts/benchmark_results)

Positive changes mean the new release took longer. The comparisons include the upstream Rust version change and Ohm changes.

The Codex editing comparisons reused the 32-core AMD Genoa machine that had finished the uv benchmarks. We first repeated the original two stock/current pairs there. Stock Rust and Ohm 1.100 averaged 485.10 and 322.81 seconds on the original host, and 493.43 and 311.12 on the second. The source tree, lockfile and selection of 3,439 final TUI tests matched on both. In the four direct Ohm pairs, the largest command-level increase was “Run the exact strict Clippy lint used during the original CI fix” at +27.48 seconds. The complete Codex replay took 49.89 seconds longer on average.

All eight cold Codex Clippy runs exited successfully. Three of the four 1.100 runs also printed a recursion-depth warning at `core/src/session/mod.rs:3113`, previously recorded during release qualification. Cargo counted five duplicate warnings in those runs and six in the other 1.100 run. The two Codex developer comparisons retained 16 runs. The host and command monitors discarded 6 additional attempts. We verified all 80 command logs and 16 CPU traces for the accepted runs.

The uv comparison uses the same import-level allowance for `clippy::disallowed_types` in both SDKs. Both ran the same strict Clippy commands. Both Ruff SDKs ran Clippy with `-D warnings`. The 1.99 commands omit one allowance for `clippy::needless_nonzero_get`, a lint introduced after that release. [Same-host measurements](previous-release-confirmation-1.100.0-1.json)
