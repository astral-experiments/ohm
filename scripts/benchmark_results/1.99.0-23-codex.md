# Ohm 1.99.0-23 on the Linux Codex TUI replay

The optimized -23 candidate took 45.7% less time than stock Rust 1.99.0 to replay the Codex TUI
development session. Both runs passed the same 3,439 endpoint tests with each toolchain.

| Toolchain               | First session | Second session |     Mean |
| ----------------------- | ------------: | -------------: | -------: |
| Stock Rust 1.99.0       |      500.72 s |       515.89 s | 508.31 s |
| Ohm 1.99.0-23 candidate |      273.04 s |       278.81 s | 275.93 s |

Four focused TUI commands exposed the -22 regression. In that comparison, they took 371.45 s
with Ohm and 12.00 s with stock. In the new comparison, they took 9.23 s with Ohm and 10.42 s
with stock. These are mean totals for the four commands, with each release compared against
stock on its own machine. On -22, the commands printed 104 Cargo compilation messages apiece.
On the -23 candidate, they printed none in either session.
[Published -22 results](https://github.com/astral-experiments/ohm/pull/229) · [Cargo fix](https://github.com/astral-experiments/ohm-cargo/pull/424)

The replay used an x86-64 Linux VM with 32 logical AMD EPYC Genoa CPUs and eight Cargo jobs.
The order was stock, Ohm, Ohm, stock. The 44 measured commands and four warmup commands
completed with no exclusions. Each run skipped the same 16 tests. The qualification build used
the Rust and Cargo pins in the release draft.
