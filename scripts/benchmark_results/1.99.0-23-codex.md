# Ohm 1.99.0-23 on the Linux Codex TUI replay

The official -23 Linux build took 45.0% less time than stock Rust 1.99.0 to replay the Codex TUI development
session. Both toolchains passed the same 3,439 endpoint tests in each run.

| Toolchain         | First session | Second session |     Mean |
| ----------------- | ------------: | -------------: | -------: |
| Stock Rust 1.99.0 |      356.98 s |       372.87 s | 364.92 s |
| Ohm 1.99.0-23     |      198.23 s |       203.19 s | 200.71 s |

The x86-64 Linux VM had 32 logical CPUs (AMD EPYC-Rome Processor). Cargo used eight jobs.
The run order was stock, Ohm, Ohm, stock, with 44 measured commands and four warmups.
All four sessions passed the CPU and workload checks. Each run skipped the same 16 tests.
