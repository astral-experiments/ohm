# Ohm 1.99.0-23 on the Linux Codex TUI replay

The -23 candidate took 47.9% less time than stock Rust 1.99.0 to replay the Codex TUI development
session. Both toolchains passed the same 3,439 endpoint tests in each run.

| Toolchain               | First session | Second session |     Mean |
| ----------------------- | ------------: | -------------: | -------: |
| Stock Rust 1.99.0       |      494.51 s |       503.00 s | 498.75 s |
| Ohm 1.99.0-23 candidate |      256.64 s |       262.70 s | 259.67 s |

Four TUI commands exposed the -22 regression. Together they took 371.45 s with -22 and
12.00 s with stock on that machine. On the -23 machine they took 7.86 s with the candidate
and 9.47 s with stock. Each figure is the mean total for the four commands over two runs.
The four commands printed no Cargo compilation messages in either candidate session.
[Published -22 results](https://github.com/astral-experiments/ohm/pull/229) · [Cargo fix](https://github.com/astral-experiments/ohm-cargo/pull/424)

The x86-64 Linux VM had 32 logical CPUs (AMD EPYC-Genoa Processor). Cargo used eight jobs.
The run order was stock, Ohm, Ohm, stock, with 44 measured commands and four warmups.
All four sessions passed the CPU and workload checks. Each run skipped the same 16 tests.
