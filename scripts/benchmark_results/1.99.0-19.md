# Compiler studies behind Ohm 1.99.0-19

Three compiler changes in this release have measurements from earlier stage-1 builds. Only the Ruff check study timed a complete Cargo command. The distributed Linux compiler uses PGO and BOLT.

| Change                                                                          | Workload                                        | Earlier result                                                                                                                                                                                          |
| ------------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Index tool-lint prefixes](https://github.com/astral-sh/ohm-rust/pull/250)      | Edit Ruff and run `cargo check -p ruff`         | Wall time fell 2.16% across 64 pairs. The 99% interval was 1.28–3.08%. Build and test-build timings were inconclusive.                                                                                  |
| [Summarize generic exports](https://github.com/astral-sh/ohm-rust/pull/251)     | Compile uv’s library test harness after an edit | Rustc executed 50.36% and 50.95% fewer instructions in two blocks. Whole-command timing was inconclusive because repeated builds also produced different public metadata hashes on the parent compiler. |
| [Defer library-directory scans](https://github.com/astral-sh/ohm-rust/pull/252) | Relink uv’s cached library test harness         | Rustc executed 5.23% and 5.21% fewer instructions on two machines. A trace recorded 519 fewer directory opens and a byte-identical executable. The counts exclude the native linker.                    |

The original pull requests retain the paired Ruff timings, the uv test-harness profiles and the cached-relink traces.
