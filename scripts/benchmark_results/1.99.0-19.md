# Incremental builds in Ohm 1.99.0-19

## Published -18 and -19 toolchains

After a change to uv’s version bounds, -19 rebuilt the library tests faster in all 16 pairs. The Ruff check and the comment-only uv edit had slightly slower medians with -19. Both intervals include zero.

| Workload                               | Accepted pairs | -18 median (s) | -19 median (s) | Paired time saved | Interval for time saved |
| -------------------------------------- | -------------: | -------------: | -------------: | ----------------: | ----------------------: |
| Ruff diagnostic edit, then check       |             16 |          5.994 |          6.079 |            -1.88% |        -5.56% to +2.84% |
| uv version-bound edit, then test build |             16 |         23.819 |         21.145 |           +11.38% |       +9.00% to +13.92% |
| uv comment edit, then test build       |             15 |          2.256 |          2.323 |            -2.02% |        -8.45% to +6.94% |

Each pair timed the same edit and Cargo command on the same eight physical cores of an AMD EPYC Milan Linux VM. Both published toolchains used incremental compilation and the upstream Wild 0.11.0 binary. Each toolchain had its own warm build directories. Each block of eight pairs ran -19 first four times, in randomized order.

The time-saved column gives the median of the within-pair reductions. Positive values favor -19. The intervals use an exact two-sided sign test with at least 95% nominal coverage. The timings compare the complete releases. [Per-attempt timings and CPU measurements](1.99.0-19-paired.csv)

- **Ruff check.** We changed a diagnostic string in `unused_noqa.rs` and ran `cargo --config profile.dev.build-override.opt-level=0 check -p ruff -j 8 --locked --offline`. [Ruff revision](https://github.com/astral-sh/ruff/tree/93526150df078af7dd8fc4226cdcc469539d2001)
- **uv test build.** We applied the fix for post-release matching in exclusive version bounds and ran `cargo test --no-run --lib -p uv -j 8 --locked --offline`. [uv change](https://github.com/astral-sh/uv/commit/73337b788c9057f6f3db1035d64be02b61b6ce7b)
- **uv comment edit.** With the fix applied, we changed the capitalization of one comment in `uv-client/src/retry.rs` and repeated the same Cargo test build.

The host had to be idle before each timed command. We excluded both halves of a pair if either half exceeded 5% other host CPU use or 0.1% steal. One Ruff attempt stopped at the idle check. One uv version-bound pair needed a second attempt. All three attempts at the last uv comment-edit pair exceeded the CPU limit, leaving 15 accepted pairs.

## Measurements behind individual compiler changes

Three compiler changes in this release have measurements from earlier stage-1 builds. Only the Ruff check study timed a complete Cargo command. The distributed Linux compiler uses PGO and BOLT.

| Change                                                                          | Workload                                        | Earlier result                                                                                                                                                                                          |
| ------------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Index tool-lint prefixes](https://github.com/astral-sh/ohm-rust/pull/250)      | Edit Ruff and run `cargo check -p ruff`         | Wall time fell 2.16% across 64 pairs. The 99% interval was 1.28–3.08%. Build and test-build timings were inconclusive.                                                                                  |
| [Summarize generic exports](https://github.com/astral-sh/ohm-rust/pull/251)     | Compile uv’s library test harness after an edit | Rustc executed 50.36% and 50.95% fewer instructions in two blocks. Whole-command timing was inconclusive because repeated builds also produced different public metadata hashes on the parent compiler. |
| [Defer library-directory scans](https://github.com/astral-sh/ohm-rust/pull/252) | Relink uv’s cached library test harness         | Rustc executed 5.23% and 5.21% fewer instructions on two machines. A trace recorded 519 fewer directory opens and a byte-identical executable. The counts exclude the native linker.                    |
