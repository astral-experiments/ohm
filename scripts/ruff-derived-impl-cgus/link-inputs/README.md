# Which inputs changed on the nine real Ruff links?

This unscored Linux study keeps Ruff's Git HEAD at `f3280423` and applies the two tracked files from `d136bd8d`. It uses the matched release-trained rustc at `025c787a`, signed −24 Cargo and Wild 0.11.0. The registered command is `cargo +ohm test --no-run -p ruff`. All native executions, Cargo logging, ptrace and the additional linker calls run outside every counter.

One history builds the original and edited source normally, checks the two diagnostics and the repair, and rebuilds the edited checkout from independently empty outputs. A separately initialized history stops the actual Wild process at exec for each enrolled executable. A second signed Wild gets the same inputs and working directory while they are live. It writes to a private output and emits a layout. Its complete ELF must match the unmodified link. The receipt binds the full argument vector, archive headers and member payloads, selected member ranges, opened and mapped present files, failed file probes, plugin options and the ELF interpreter. The original cargo, rustc and linker keep their ordinary arguments and environment. An unexpected argument or thin archive rejects the corresponding inspection.

On one real integration test a separate control adds an earlier native search directory. Its initially empty case must reconstruct the original ELF. An added link script and constructor must change both the native executable and its exit value. The control then changes an object at the same length, inode and mtime, requires the new exit value, checks a malformed input and verifies exact recovery. The installed SDK and Ruff inputs are untouched.

A third independent history enables Cargo's own fingerprint tracing, starting before the cold build. The worker retains the actual test dep-info and fingerprint records. The historical package and real binary path are relevant because reading a binary's bytes during compilation and running it from a test have different dependencies. `binary_edge.py` exercises both.

`registered.json` binds every output name and both authentic preceding pilot archives. Every image keeps its binary identity within a compiler and phase. Native equality is an observation about these two inputs. Any proposal to suppress a shipped linker must establish a valid proof for other code, scripts, libraries and missing search candidates.
