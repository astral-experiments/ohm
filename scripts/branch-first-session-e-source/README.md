This source-only GNU job builds E, `6ab0440ccdc955d26984b7b900fc361774471e3e`, a direct child of K, `0afbeff303d3658bff52582d8f1a996d59e6c8ce`. Both real compilers open the same incremental directory. One case starts K directly on E’s cold packed A without an intervening branch switch. Another returns K to that same unmodified E-produced A after E builds B. E independently reads K’s raw A and an older packed K A. Each reader must satisfy the compiler’s actual loaded-state assertion, link the unique A-specific sentinel, map both decoded tables and reproduce its own independently empty A executable. The original traced file operations, complete source table payloads and executable bytes remain in the observations.
