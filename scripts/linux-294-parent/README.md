# Migrate two poisoned signed Ruff targets to strict Cargo

The 60-visit adjacent-commit experiment reproduced the Linux regression on signed Ohm 1.99.0-21. Cargo #294 discarded the compiler's v1 native dependency marker. The comparison here uses signed 2d44bd4a and one exact Cargo 761ea115 from builder 41151297839. Both commands use the same signed compiler, driver, GNU linker search driver, stock Wild, sysroot and native host. The candidate joins existing #291/#292 with #305/#306/#308. It retains #292’s checked-native v2 migration fingerprint. [Adjacent-commit evidence](https://github.com/astral-experiments/ohm/tree/8b6d208b982fb3cb4a803a2976934c80bfcc66b5/scripts/linux-294-parent/result)

Each of two independent installations warms and repeats signed Cargo without a provider, then adds a new earlier valid or malformed library and demonstrates the returned stale success. It atomically replaces the Cargo ELF at the same absolute path, preserving its mtime. The target and shared directories keep their device/inode, source, paths and contents through that swap. Both upgrades and their repeats must observe the actual provider and GNU Wild. Valid 83 must match both clean readers and generated Rust; malformed must make the native link fail. Replacing the valid provider with 47 and then malformed bytes retains its device, inode, length and mtime. Removing it must repair the result. Each Cargo gets its own empty installation for all four provider states at the same canonical path.

The source control restores Ruff's actual vendored alias normalization function and its call in the generator from 26911caa28 in a disposable copy of 93526150. An independently compiled reader asks for both `NEW LINE` and `NEWLINE`. The former returns ten before the edit, the latter after it. The changed build, its repeat and its repair after the deliberately missing Rust name must match the separately empty edited build byte for byte, and restoration must recover the original ELF. Metadata commits to the preimage, complete historical donor, postimage and patch.

All acquisition calls are ordinary `cargo +ohm build -p ruff_unicode_names2 --locked --offline -j4 --message-format=json`. Source and native injections happen outside these calls. The validator counts physical full rustc, codegen-reusing link-only rustc, and Wild separately in the saved process traces, and reopens actual linker and generator file opens. The native host build script cannot use #292’s final binary/test cached-object route. The released Rust and Wild are unchanged. The experiment records how much work this particular correct link costs, without timing or performance thresholds.

From an authenticated packaging clone with Linux runner quota, switch to the named QA ref and run the job.

```sh
gh workflow run ci.yml --repo astral-experiments/ohm --ref charlie/qa-signed21-294-292-target-migration -f stage=provider
```

The acquisition enrolls the original short-lived Cargo artifact by run, artifact id, length, ZIP SHA-256, executable hash, build-record hash, Git source and complete signed SDK manifest. The build recipe is permanent. A later fresh build needs a correspondingly registered digest; the current job deliberately refuses to substitute different binaries. Artifact receipts retain the process observations, complete compressed native readers, generated sources and raw compiler and Cargo dep-info. Python 3.11+ and `b3sum` (or Python `blake3`) can recheck the native marker trailer offline with `python3 -IB verify.py PATH_TO_RESULTS`.
