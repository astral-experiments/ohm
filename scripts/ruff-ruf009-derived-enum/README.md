## Local preflight and later dispatch

The local preflight takes a Git donor containing the registered modern Ruff commit and the directory containing the signed modern check and historical native receipts. It runs six real source transitions without changing the donor, decodes each actual signed rmeta, and checks the independent published hash, genuine historical probes, four settled monitors and explicit negative controls. Synthetic numbers in its isolated statistics self-test have no bearing on a performance result.

    python3 -IB scripts/ruff-ruf009-derived-enum/preflight.py /path/to/ruff /path/to/private-derived-enum-check-01

Before pilot dispatch, insert the independently verified factory head, branch, positive factory run, exact P/C source SHA, and receipts/kit artifact [name,id,bytes,sha256] into factory.json, following scripts/ruff-linter-check-attribution/scope-adt-factory.json's inner format.
