# Which parts of the signed Rust compiler run after Ruff's notebook fix?

A fresh GNU x86-64 worker builds the real eight-file Ruff #29308 edit in both directions. This experiment studies the unchanged signed Ohm −21 compiler c79998a5 and strict Cargo 761ea115. Its exact ordinary command is `cargo +ohm test --no-run -p ty_server --test e2e --locked --offline -j8 --message-format=json`.
