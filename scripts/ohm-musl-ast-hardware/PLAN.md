## Admission

1. Demonstrate on real normal Cargo commands that a whole locked target compile repeats after the registered edit, that the candidate actually removes it, and that registry host build scripts and target products are counted separately. Trace launches separately from the scored commands.
2. Prove the true old and corrected visitor behavior with a downstream native client, compare the complete ELF of edited, repeated, repaired and independent same-path clean builds, and require the genuine compiler error from a bad edit. Separately demonstrate that an actual input read by the Rust assembler is still live and that a downstream musl executable with a native archive still changes or fails on search priority, same-inode/size/mtime replacement and corruption. Check the old Cargo reader, the upgraded reader and a same-path downgrade on an already populated workspace.

A second stored copy of codegen or the linked product disqualifies the candidate. Record any one-time migration explicitly. Document repeated build-only or test-only differences separately.
4. Use two fresh workers in opposite orders as a screen. Proceed to the primary measurement only if both have a whole first-repeat ratio of at least 1.8 and all foregoing checks pass.

## Decision

Count 12 new paired hosts in each scored cohort with six parent-first and six candidate-first positions fixed before data collection. Use one physical source path, compiler install path and imported dependency inventory per paired host. Start each role with private, equally populated state prepared by the exact cold/edit sequence. Prove the real compiler, rustdoc, Cargo and stock Wild selections. Rearm caches between roles and keep hardware-counted commands free of tracing. Admit only complete inherited user-mode hardware instruction counts, validated by parent, child, grandchild, exec and thread controls, with at least 99.5 percent counter coverage. Record failures and retain all raw output.

For each complete cohort report the median of paired parent/candidate ratios, the exact distribution-free median interval from the third to the tenth ordered ratios (96.14 percent coverage under independent host sampling), and the one-sided sign-test probability against 2x. The first cohort qualifies for a second independently collected cohort if its lower interval exceeds 2 on the primary endpoint. Open the performance draft only if the second cohort clears the same threshold, the median edited command does not regress more than 3 percent in either cohort, and all behavior, storage and compatibility checks pass. Report secondary endpoints regardless of direction. No optional extra hosts or switching endpoints after seeing data.
