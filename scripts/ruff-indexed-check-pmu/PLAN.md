# Ordinary Ruff check on two matched compilers

Build parent and candidate once with identical pinned stage0, LLVM, standard library, Cargo and linker. Authenticate both frozen compiler installations against factory run 41384874631. The immutable source, crate inventories, exact P and C revisions and original performance-counter sources are recorded in registration.json.

For each real edit, run eight PC/CP pairs on two fixed physical cores. Restore each arm's own complete A artifact directories into the same absolute path, require a fresh ordinary A check, apply the entire Ruff diff, and count the ordinary edited check including all descendant workers. Require the registered compiler inventory, the changed typed client verdicts and a fresh repeat. An empty B target independently checks the same client verdicts. Per-pair effects are computed as one minus candidate instructions divided by parent instructions. Report the median, paired bootstrap interval, exact two-sided sign test and all raw counts.

Use inherited native userspace retired instructions only when process, thread and exec calibrations all reproduce their counted loop and each event has equal positive running and enabled time. A failure selects separately calibrated Valgrind guest instructions for the whole study. The two counter domains are never pooled. Raw Cargo stdout, individual diagnostic streams, before and after graph sizes and hashes, counter outputs and effective CPU topology are retained.
