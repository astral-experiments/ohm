This diagnostic uses two fresh native x86-64 Linux hosts. Position 01 runs Eoff, Kon, Eon. Position 02 reverses that order. K is the previously qualified packed-object compiler. E is its prospective direct child which packs the first eligible checkout's two compiler tables in its own private working directory. Eoff uses Cargo's normal defaults. Kon and Eon add only the existing branch-cache opt-in. The same strict Cargo at 761ea115 and signed Wild run at the same physical paths. The pinned subject and authentic source certificate are required before either host runs.
