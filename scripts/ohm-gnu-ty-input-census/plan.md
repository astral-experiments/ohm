Use the actual GNU cross linker and the workspace's default dev profile. Require both new named tests to appear only after the edit and run them on AArch64 through QEMU. Retain the complete Cargo streams, physical kernel execs and the depfile content bound to each local compiler's output directory and filename. Preserve unresolved cases.
