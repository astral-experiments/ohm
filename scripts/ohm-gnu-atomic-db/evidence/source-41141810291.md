# Rebuilding the Ruff library comparison from source

All five jobs in the unscored source qualification passed. On clean workers, the workflow rebuilt Cargo #301, the #283 parent compiler, the candidate and the complete host and AArch64 standard libraries. It assembled the first SDK from 119 checked files and changed only the LLVM-backed rustc driver to form the second. The 142,781,688 candidate driver bytes exactly reproduced the earlier build. Strict Cargo reproduced SHA-256 `9fb29f6abecad05acb6015990615c5fbb435a5907543f0bd33cf88cada4f5826`. The existing Wild executable has the same checksum in both kits. An independent reader streamed and hashed every regular file in the 264,094,692-byte source-built parent transfer, the separately rebuilt candidate driver and the full Cargo executable.
