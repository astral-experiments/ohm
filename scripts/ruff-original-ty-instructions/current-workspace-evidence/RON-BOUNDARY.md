The complete signed -23 Ron compilation cost 9.325 billion user instructions on the restored workspace role. All 16 native derives executed before rustc finished analysis and collected checked relink inputs. Both orders measured 2.091 billion at that boundary. Full metadata existed at entry to the LLVM backend, at 2.410–2.411 billion. Both stops deliberately killed the compiler and produced no rlib. Two complete debugger runs cost 9.302 and 9.304 billion, both returned the original archive and both executed the expected native consumer. Each clock was unscaled, and two native worker threads retired the expected 8 and 32 million arithmetic instructions in each hardware calibration. ## A real incremental compiler failure

The matched role added only `-Cincremental` to the actual current-Ruff arguments. Its cold compiler and native consumer succeeded. On the first unchanged invocation, each of the previous rlib, rmeta, and dep-info files was still at its original path. The signed compiler reopened its saved full metadata, then its only operation on the new temporary `stub.rmeta` was a read-only open that returned ENOENT. The normal cold compiler and an independently empty session both created and then read their own stub. Both executed the same typed consumer. The two renamed diagnostic output directories that caused earlier harness refusals are separate from this third, output-preserving experiment. [Native filesystem originals](https://github.com/astral-experiments/ohm/actions/runs/41628218885)

The introducing Ohm commit moved stub generation after fresh encoding to use the new hashes. Its preexisting shortcut for a green full metadata work product still returned before that code. The prior commit generated the stub before trying reuse. The approved source at d57 reopens that per-invocation temporary stub when separate metadata is requested. Signed Cargo applies the separate format by default to non-root registry or git dependencies and normally restricts incremental compilation to path sources. An explicit separate-metadata request on a local incremental rlib can reach both settings. ## What normal incremental reuse can establish

In a separate diagnostic, requesting embedded metadata allowed the stock incremental compiler to finish. Training took 10.293 billion user instructions, compared with 9.328 billion for the original nonincremental command on that boot. The two warm calls cost 760.28 and 769.88 million. Each newly finalized session contained 68 native objects whose name, filesystem device, inode, and full SHA-256 matched the prior session. We sampled those identities before and after each invocation. The invalid Serde DSO produced both E0782 errors, including bitflags line 17, columns 37–98. A real returned-value perturbation changed the consumer from 2 to 1. The independent clean edit also yielded 1, the repaired original yielded 2, and a separate type error produced E0308. [Counters and native results](https://github.com/astral-experiments/ohm/actions/runs/41628218885)

This comparison changes the registry role's incremental and embedding settings. Training stored 20,561,920 bytes of session files. The second warm session occupied 21,172,224 bytes. The full-metadata incremental rlib was 3,757,298 bytes versus 2,328,586 for a cold split-metadata incremental rlib. The warm rlib digests varied despite the 68 physical object matches and identical standalone rmeta. Source roles and counts therefore do not establish either complete same-output evidence for downstream consumers or an ordinary Cargo speedup.

A safe producer-side proof is available for a codegen unit **only** with its previous work product and a green codegen-unit node under the native-input guards. The signed ordinary registry role has no incremental graph. Replaying one previously observing derive can miss a different derive's first observation. An earlier real error also passed an expansion-only stop. The signed driver instead expands the complete crate, checks its complete normal analysis and native inputs, and only then can enter the codegen pipeline. Cargo's existing unchanged-interface signal covers metadata-only dependency edges. Native consumers wait for the complete artifact. A safe workspace cutoff still needs actual full native-input and downstream byte/identity evidence.
