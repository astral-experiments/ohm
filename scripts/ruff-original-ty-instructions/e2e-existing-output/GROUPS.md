# Reproduce the .rodata header with the distributed Wild

Run 41708042435 stopped before even the first OLD donor qualified. A second complete stock Wild on the same 446 arguments, source files and current temporary objects produced a single differing .rodata section-header byte at file offset 227975768 (0 versus 8). Only its derived GNU build ID changed inside sections. The complete OLD executable sizes were both 227977696. Each full BLAKE3 preimage and all 42 section payloads/headers were read before the worker exited. The distributed stock OLD recorded separately had the same complete SHA as the private source arm. The two SHA-256s are 6d3724468395065d8eb0721eac41893b01e38ffe69eeeb88a59419886ab7a893 and f203086dc58594dc33899d25dcbdcd5ec86d04e3dfb493efe7c7a59f6abd97e2.

One possible input was missing from that serial comparison. The second linker inherited Cargo's jobserver *environment*, but Python closed the descriptors. The exact original CARGO_MAKEFLAGS hash decodes to `-j --jobserver-fds=5,7 --jobserver-auth=5,7`. Source Wild selected one worker. Wild derives default file groups from the available native worker count. It merges .rodata section attributes inside a file group, then overwrites the output entry size once per contributing group. The final emitter writes the maximum of this value and the built-in size (zero for .rodata).

This one worker screens that explanation on the first real ordinary OLD command and the real edited NEW command. Each selected source Wild actually finishes a full link. On the same current 446 raw arguments and all 409 checked files, stock Wild executes before and after with the real original jobserver file identities and CPU mask where obtainable. The earlier closed-descriptor case stays separate. Four stock runs receive private matching pipe descriptions at the original FD numbers, with 0, 1, 1 and 0 available additional tokens. For these controls the native command and environment stay identical. The worker records pipe device/inode, access modes, occupancy, and return of every private token. The end-to-end actor, every same-thread-count signed comparator and both signed repetitions must agree on the *entire ELF*.
