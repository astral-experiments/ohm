# One ordinary Ruff e2e link

This experiment changes the native linker in one ephemeral signed Linux SDK. It builds the normal 55 default members and 102 test executables after the reviewed Ruff #29697 edit. The ty_server e2e executable includes 200 real tests. Every other target transfers control to the original signed Wild ELF with its original argv, environment, working directory and inherited GNU jobserver descriptors. A kernel exec trace on an unselected command verifies the transfer before the workspace build.

Only a completed, successful full link in this same run can donate a receipt. The experiment holds that small receipt in the live QA coordinator. Fresh cc, collect2 and Wild still run on every attempt. Wild reopens its selected regular inputs, then runs its normal linker-script and typed object loader. The candidate consumes the same immutable snapshots, over 600 MB for the historical donor. It compares every ordered lookup and resolved byte sequence. It binds the actual group thresholds and each ordered object's original owner, archive range and symbol count. Signed Wild 0.11 can select a different section-header value at different worker counts. A completed normal link must corroborate the entire predicted group roster.

On a hit, the reader copies the existing canonical ELF into a temporary private buffer and verifies object identity, size and content through the read. The stock output writer publishes all 228 MB on a fresh inode using its ordinary mode and finalization. A held O_PATH capability is reopened for writing after publication. The write must affect only the old unlinked inode. The candidate retains one output. Its stored state inside the QA coordinator is just one receipt.

The OLD executable must fail on the NEW fixture before the edit builds. Complete local output and independently empty full signed NEW must have identical native bytes and the expected changed test verdict and 200-test inventory. Two additional untouched signed runs capture whole-workflow hardware and elapsed controls. Misses exercise changed Ruff input, two earlier library forms, altered transient symbols, malformed input, an input saved during its actual read, existing corrupt output bytes, same-size/mode/timestamp replacement, and output mutation or atomic replacement halfway through the actual read. Terminal errors and repairs are retained.

This is one functional pilot with one source-treated target. Untouched signed whole-root measurements, the source no-reuse control, and candidate observations stay separate. Hardware and elapsed clocks cover only the build. The coordinator has a separate retired-instruction count. Matched signed link diagnostics are labeled separately. A product speed claim would require a prospectively registered independent whole-workflow comparison.
