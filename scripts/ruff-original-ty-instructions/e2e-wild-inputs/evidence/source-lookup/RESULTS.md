# Wild's actual file lookups in Ruff's ty_server e2e link

The stock Wild 0.11 source can expose the complete library search for this x86-64 GNU link. An observer on the two callers of `Input::path` attached a source position to each command-line input and each child of a GNU linker script. It recorded the result of the existing filesystem query for each candidate and the actual opened file descriptor's device, inode and length. Both source-built executables used upstream commit `e856d81f6683cad80b9fe0ebf1a0c3c403c6fe11`. The distributed Ohm SDK continued to use its original Wild. [Source patch](../../lookup-diagnostic.patch) · [Source and lock hashes](source-ids.json) · [Native worker](https://github.com/astral-experiments/ohm/actions/runs/41671338175)

The independent reader matched all 402 top-level inputs against the original 446 arguments in order. Three scripts requested seven child inputs. Every ordered lookup matched an actual stock kernel sequence. The observer reported 409 opened inputs, including the temporary 39,760-byte `symbols.o`. Each input matched a successful signed-link open, a mapping of its resolved file and the size returned by the kernel on its actual descriptor. Stock's syscall dump abbreviates inode numbers. The observer's inode values come directly from its own open file handles. [Full readback](verified.json.gz)

The healthy link had 14 successful candidate checks. All seven additional requests came from the actual chosen scripts. `libgcc_s.so` requested `libgcc_s.so.1` and `-lgcc`. `libm.so` requested `libm.so.6` and `libmvec.so.1`. `libc.so` requested `libc.so.6`, `libc_nonshared.a` and the ELF loader. The separate failed check for the output path came from Wild's output replacement logic. The first search directory's valid archive displaced the system `-lutil` winner. The malformed version was interpreted as a GNU script and introduced four additional child names with 14 failed searches each. All healthy inventories contained the same 200 tests. The withheld OLD executable failed the changed `debug_command` fixture and the edited executable passed. The signed kernel trace also contained nine missing loader inputs before the first Wild library probe. These were five attempts to open libc or libgcc in the toolchain library path, three checks of glibc-hwcaps directories and one check of `/etc/ld.so.preload`. The loader opened `/etc/ld.so.cache`. Of the six previously unleaseable system arguments, Wild opened the five CRT objects. The original driver passed `liblto_plugin.so`, `lto-wrapper` and a temporary resolution filename. Their handling by GCC and its driver processes is outside these linker events. This command contained zero response files. The QA reader admits the observed ASCII paths and regular-file search successes. [Complete kernel and source evidence](verified.json.gz)

The next bounded test can use the existing retained `.rlink` to regenerate `symbols.o` and compare the complete bytes with the consumed object, including the four-byte refusal. Signed rustc already serializes `CrateInfo::linked_symbols` and constructs the exact byte vector in `add_linked_symbol_object`. Accepting a reused link would additionally require a coherent generation of every provider and earlier search location, and coverage of the external driver and loader. A descriptor hash sampled after a file changes cannot establish which bytes an earlier link consumed. [Retained crate information](https://github.com/astral-experiments/ohm-rust/blob/d57fd1515986dccecdcece8da85e651bfb4b81f9/compiler/rustc_codegen_ssa/src/lib.rs#L279-L286) · [Object construction](https://github.com/astral-experiments/ohm-rust/blob/d57fd1515986dccecdcece8da85e651bfb4b81f9/compiler/rustc_codegen_ssa/src/back/link.rs#L2628-L2633)

Source instrumentation here has no performance score. The previous signed whole workspace required 80.004B instructions on unchanged `cargo test --no-run`. Keeping the 9.331B Ron compile and hashing the distinct surviving explicit inputs once left 26.791B for all remaining work to reach 2×. Hashing every occurrence exceeded the 2× budget by 3.712B even before the other work. Upstream Wild's existing depfile and trace report selected inputs, Ohm Wild's depfile fixes preserve escaping and replay placement, and Cargo's declared-archive reuse has a separate eligibility check.
