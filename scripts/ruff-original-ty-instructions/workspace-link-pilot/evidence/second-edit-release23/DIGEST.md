Halving this stable signed command requires removing 25.463B more instructions. Removing the entire coordinator for free would still require 17.241B of source savings. Eliminating just a second equal-cost pass from the same bytes cannot save over roughly half of the 38.109B source price, even if every source instruction had belonged to such a pair. With the actual coordinator this ceiling misses the target by 6.409B. Using the separately measured per-role hash prices, carrying a digest through the immutable input and the verified full-output copy would save about 16.214B. That projects 49.252B with the existing coordinator and 41.029B with a free coordinator, still 1.026B above half. These are design estimates for the diagnostic implementation. These complete input hash passes are specific to the QA implementation.

At acquisition, the digest belongs with the actual private byte allocation, open descriptor and stamp. An immutable borrow of those same bytes can carry that digest when passed through the loader. On a fresh accepted output, the existing binary is still completely read from an open regular single-link descriptor, checked by BLAKE3 and generation, and kept open. The sole writer closure copies its entire immutable buffer to an equally sized exclusively owned BufferThenWrite allocation before a normal full write. A digest can describe that copy by construction if it is confined to this closure. Preserve the new-file exclusive create, inode and link-count tests, collision handling, write/permission failures and the full post-emission read of a genuine full donor. Hashing the old file and checking its generation catch real corruption. A hash of the second private buffer cannot detect an unrelated writer changing the named file after publication.
