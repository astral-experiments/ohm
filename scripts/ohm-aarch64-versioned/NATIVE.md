# Native versioned-reader registration

Compiler construction ended with exit 1 because its fixture imported a different
module of the same name. Both source-built products, the full 119-member SDK
custody, Cargo's marker unit and the two Linux-host Rust run-make suites had
exited successfully. The original actions, status, raw job log and four
artifact identities are frozen in qualified-builds.json. Reconfirm the two real
old/new compilers on the same 24 checked-in GNU assembler forms, native archive
guards and missing-file failures. Resolve the classifier by its original,
explicit source path. Reopen the signed, #293 and aware Cargos by source and
complete ELF. The independent qualification issues no statistical samples.

For each of the three Cargos and the new compiler, run each direct/rlib fixture
with no file watch, a directory watch and an explicit file watch. Compare each
changed, missing, malformed, recovered and same-stamp native provider against
its unshared empty targets. Check every successful program under QEMU and the
complete body. Use the literal GCC, collect2 and GNU ld execs and the successful
provider descriptor opens to attribute an actual native result. Old Cargo
with the unknown marker must execute a regular crate compiler on the terminal
unchanged command. Authenticated Cargo LNK1 trailers in the real translated
depfiles must describe only the versioned-aware matching cases.

Run the legacy compiler on the aware reader as a separate backwards-compatibility
case. For each earlier Cargo, additionally alternate the physical Cargo image
with the aware reader on one actual source/target/shared root. Keep source
and compiler intact, restore the earlier Cargo inode on downgrade and test
a real provider and both valid and invalid independent empty results on both
sides. Each phase keeps original native bytes, source depfiles and raw trace.

Run a real host-built proc macro that calls proc_macro::tracked::path from
the ordinary cross-built rlib, both alone and with the new marker in its
assembly. The ordinary tracked name can equal the original marker, the
versioned marker, or both. Check the separate real output and depfile
prerequisite rules, authenticated trailer, raw compiler invocation of the
producer rlib and successful AArch64 consumer against its own empty copy.
With no real tracked reserved path the aware Cargo may keep this rlib fresh.
With a collision, an unchanged ordinary command must physically compile it.

The native groups and their independent readback must pass before final
Ruff instruction samples. Incidental process counts and any failure remain
in the raw evidence. Elapsed time from any source build or fixture is outside
the study.
