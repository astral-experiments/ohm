## Decision

This single-host run measures a **baseline**, without an optimized arm. Continue only if the edited invocation exposes a rustc-owned computation with a plausible, disjoint budget of at least 20% of the responsible compiler invocation, or a route to approximately 2× the complete ordinary command. Preselected work includes unnecessarily rerun native codegen in the substantial consumers and repeated compiler front-end or backend traversal in the actual changed unit. A dirty Cargo message, a matching object digest or a sample count alone cannot establish removability. If the large consumers already bypass rustc and the remaining work is chiefly native linking or an irreducible changed compilation, close this edit as a negative for the larger compiler objective. Missing hardware or incomplete attribution is inconclusive. No optimization effect, significant PR claim, or release decision can be made from this baseline.
