# Compare the same AArch64 native provider with conventional Cargo

The earlier exact compiler comparison is preserved at e46fcee1579af2823f8413944635a8314086bf75, run 41139771526. Both roles had the same stale program on five unwatched bundled histories. This independent comparison attributes that behavior. A new shadow is a change to the search namespace. An existing filename and a search directory are concretely different declarations.

Five independent subjects use the same executable-producing, offline AArch64 workspace, compiler/emulator/native probes, mutations, clean inputs, forced-root and forced-producer interventions. The official stable Rust/Cargo 1.99.0 kit includes its original host and GNU target std; the exact distribution manifest and every downloaded component are checked. Signed Cargo 2d44bd4a runs with Ohm defaults disabled and then separately with defaults enabled on the same #283 compiler. Source-verified prior Cargo #293 at 735e1528 runs with either the #283 or the atomic candidate compiler. Official, signed and source-built identities are explicitly retained.

All five subjects visit five unwatched effects: preserved timestamp replacement with the same filename/inode/size, insertion of a valid higher provider, malformed selected, removed selected, and malformed higher. Stock and signed-defaults-off separately declare both search directories, just the current winning file, or both candidate filenames, including the initially missing candidate. Distinguish a normally rewritten file from preserving its timestamp even when the file was explicitly declared. In each subject repeat the positively declared new-shadow control; the two prior-Cargo subjects also test preserved-timestamp directory metadata and an ordinary rewrite of the selected declared file. Comparisons are physical verdicts, not timing. All final runs are cross-compiled for genuine GNU AArch64 and executed by QEMU.

The in-place timestamp-preserving case makes the last write earlier than an ordinary Cargo source freshness check would observe. The test makes no advance assumption that it will be detected. All native inputs and declarations are recorded in the source snapshot, and each mutation is first run through an independent C executable under QEMU.
