# Production rustc instructions after the uv workspace edit

This independent study compares the production compiler with #318 on Ohm −22 against the same source with #296 and #306. Both GNU SDKs come from the same previously qualified PGO/BOLT build. Cargo is the exact signed −22 binary. The scenario is the landed uv #20988 edit, followed by ordinary workspace-root `cargo check --locked --offline -j8`. [Compiler builds](https://github.com/astral-experiments/ohm/actions/runs/41374825846) · [Separate whole-command panel](https://github.com/astral-experiments/ohm/actions/runs/41379994255)

Two prespecified rustc invocations carry the endpoints. One checks the terminal `uv` library. The other checks the `uv_resolver` library with the workspace root's `clap` and `schemars` features. The off-clock kernel observer matches all 18 compiler executions, checks each exact argument list, and enrolls the two library selectors before counting. The hardware pass opens a separate unmultiplexed retired-userspace-instruction event at each matching kernel exec stop. Each event includes the selected rustc process and its own threads. An on-host fixed-work test checks serial work and three-thread work, excludes a forked worker's work and rejects a selected image that re-execs. [Counter source](https://github.com/astral-experiments/ohm/blob/9abd7452ac090f69aeae632f02a32be7b9a2a3cc/scripts/rustc-thread-instructions/per_rustc.py)

Each compiler gets eight freshly built pre-edit states on one host. In each group of four pairs each compiler runs first twice. Each arm restores exactly the same pre-edit state for uninstrumented Cargo, Cargo's verbose transcript, an off-clock argument capture, and the separate counter visit. All four must produce identical bytes for all 70 workspace metadata products. The original independent-cold two-build semantic checks, per-definition and allocation comparisons, two real source fixtures, 641 Cargo rows, genuine 18 compiler PIDs and both producer-qualification checks remain mandatory. An incomplete panel produces no estimate. The original wall/whole-command trial remains separate.

For each library the independent reader reports eight exact control-to-treatment instruction ratios, their paired median, two holdout medians and both order-stratum medians. The threshold for 20% fewer instructions is 1.25×. The two-endpoint family uses a one-sided matched sign test and Bonferroni adjustment. Ties count as non-wins. Qualification requires all eight ratios and every stratum median strictly above 1.25×, with adjusted p below 0.05. Under independent matched signs, the minimum observed ratio gives a simultaneous one-sided lower bound for the two median ratios with at least 99.21875% coverage. All values are specific to this real edit and this host.
