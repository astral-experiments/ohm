# Two ordinary private-enum checks

One structural worker tests two independent, unmodified Ruff Git transitions with the source-matched P3/Q3 compilers and the same checksum-validating Cargo client. Its only endpoint is which real downstream rustcs execute. The worker has no hardware counters, timing claim, confirmation allocation or product publication.

* The LineIndex history is fix #25492. It runs `cargo +ohm check -p ruff_python_literal --lib --locked --offline -j4 --message-format=json`. A separately linked reader distinguishes CRLF (2 versus 1) and preserves LF and final-line offsets.
* The Unicode history is the actual upstream-loose-matching revert. It runs `cargo +ohm check -p ruff_unicode_names2 --examples --locked --offline -j4 --message-format=json`. The three existing examples are character, count and name. The ordinary compiled character example must accept the canonical name in both revisions and reject the former loose spelling only on the edited revision.

Each role starts with independent outputs in the same canonical paths. It checks OLD, OLD unchanged, edited, edited unchanged, reverse, invalid E0308 and repaired, then a separately empty edited checkout. A separate native old/edit/empty history exercises the source behavior and retains the entire consumer ELF per distinct digest. Each typed check records the complete producer and selected library metadata, public header and per-definition rows, kernel compiler argv, physical driver contact, fresh flags, terminal status and actual external crate roster. A qualifying structural result requires a real producer on edit, a stable child producer public hash despite changed bytes, an actual downstream process in P that disappears in C, independently clean and repaired metadata and native controls, and no selected get-size artifacts. Public API changes, continuing consumers, native drift and other refusals remain reportable results. The old 7→2 RUF009 pilot contributes zero observations.

The worker uses its existing matched factory, four private native/check roots per case/role across the histories, an independent empty native reference, and explicitly preserves every record on refusal. It will not trigger a PMU run.
