# Allocated storage of an incremental full Ruff build

This hosted, disk-only experiment uses Ohm Rust `eb15cd3dc0ab0404f8ad18589569e05a70a4d401` with its branch option off (Off), `b676a640c76193a0e241d2517a64e37e156659b9` with `-Zohm-branch-cache=yes` (Full), and the candidate with the same option (Packed). Match both compiler builds' stage0, std and LLVM, and take Cargo and Wild from the signed `ohm-1.99.0-20` Linux archive using the existing packaging study's verified hashes. All options use the same source, SDK, target, shared-build and reader paths. Every installation and each clean reference starts with independently empty output roots. No Cargo wall-time endpoints are recorded or scored. Earlier H9 results supply the historical behavior checks only.

The real public Ruff transition is `b5dba861cc38e3f7fb4524c9ceba3e01a474ea13` to `7b13f01ba1569887a25670820764b24c206da8e5`. Verify the parent, both Git trees, 169 changed paths, Cargo.lock and all 505 checksummed registry archives. Run `cargo +ohm build -p ruff --bin ruff --locked --offline -j4 --message-format=json` for empty A, first B, return A, return B and unchanged B. Require the complete, identical 375-unit typed graph. Verify every empty installation compiles all 375, both return sources rebuild the genuine changed Ruff units, and the unchanged visit rebuilds zero. Require identical complete dirty-unit sets across the three signed-Cargo arms on each matched switch. Physically trace at least one independent cold per option and all selected switch/unchanged checks using the actual native compiler and signed Wild. Verify the branch and native-input flags on the Ruff binary, AST and parser processes; retain the complete native roster. Preserve all Cargo JSON exits and raw outputs.

For each option and branch produce independent same-path, empty native references before scoring. Compare the complete native CLI and linked AST reader to its own option/branch reference byte-for-byte. Across options require identical executable sections and executable PT_LOAD bytes on each branch and identical reader outputs. Keep raw ELF section digests and nonexecuting differences visible. Check all seven established Ruff CLI results, valid formatting/lint of a real f-string, an F541 diagnosis and fix that round-trips, and a malformed f-string. Require the AST reader to report 64 on A and 56 on B and reject the contradictory Rust layout. A real invalid parser body must fail with E0308 and repair to its original exact executable. The native fixture switches real Git branches, changes a linked C archive from 17 to 29, breaks that archive, and compares its repair to an independently empty binary. Verify a real packed older native object for the Packed treatment.

After each successful Cargo command fsync regular files and directories only inside the two owned roots. Independently reconcile Python lstat, GNU stat, GNU find and GNU du, counting each `(device,inode)` and `st_blocks*512` once in their union. Report each root separately, their shared inodes, older-session and packed-object bytes, and the complete per-name physical ledger. Calibrate the production readers on a sparse file, a hardlink crossing roots and dangling/directory symlinks before each cohort. Stop if the two trees cannot be independently addressed, reconciled or measured. Settled allocated bytes are the endpoint. The isolated worktrees are the only disk scope; repeatability material and clean binaries live outside them.

The first two fresh triplets are Off/Full/Packed and Packed/Full/Off. Require every Packed–Full reduction to be at least 32 MiB AND at least 1% of Full after first B, both returns and unchanged B, plus every source, storage and native safeguard. If this gate passes, run six new triplets, one of each order, shuffled by seed `0x283350D1` before any observation. Require the same per-triplet gate at all four endpoints and report every absolute allocation and paired difference, including Packed versus Off and the cold baseline. The confirmation excludes pilot data. Retain failures, print the reason for stopping, and preserve portable receipts. CI never publishes a release.

To reopen the portable receipts, extract the pilot artifact into `logs/` and the confirmation artifact into `logs/confirm/`. Run `python3 -IB logs/reproduction/scripts/ohm-packed-ruff/full-cli/verify.py logs screen` and replace `screen` with `confirm` for the six new triplets. This decompresses and verifies every unique cold native executable, reconstructs the physical-inode totals and checks the original Cargo, CLI and typed-reader observations.
