# GNU renderer example instruction ceiling

`cargo +ohm build -p ruff_annotate_snippets --examples --locked --offline -j4 --message-format=json` still compiles and links twelve examples on the GNU host. This diagnostic asks how much work could be removed if every example compiler frontend became free and every native link still ran. It uses the existing signed Ohm `-21` compiler, standard library, rustdoc and Wild with the original #301 Cargo binary. Its source and expected source checksums come from the frozen two-file Ruff edit. [Ruff edit](https://github.com/astral-sh/ruff/commit/9c53b5de3aae4b1832eb7ee137647dda2466f888) [Compiler distribution](https://github.com/astral-experiments/ohm/releases/tag/ohm-1.99.0-21) [Source-built Cargo](https://github.com/astral-experiments/ohm/actions/runs/41081958994)

The preregistered plan is byte-for-byte in `PLAN.md`. `roles.json` records both worker orders and the current Cargo subject, and `registration.json` retains the preceding measurement's Ruff, patch and normal command. Both workers create independent target and shared directories at the same visible path for each installation. The two fresh SDK directory trees hardlink original immutable files, preserving physical compiler identity while separating all build outputs. The edited command and its first unchanged repeat run consecutively, followed by a topology-only control and an independent clean build. The script reads the commands' raw outputs after the pair. It runs the twelve example programs, compares their complete emitted file hashes and sizes, and exercises the actual old and fixed `multiple_insertions` test outside the counters. Edited program bytes are established on the independent ordinary native replay. The artifact identities from both enrolled commands remain in their unaltered Cargo JSON.

Each traced example has its own inherited instruction event starting at successful `exec` of the physical rustc, one event at `cc`, and one at the released Wild. Each `collect2` and Wild child is matched to its own compiler output. The verifier independently walks the kernel fork and thread group ledger. It requires every child to exit and recognizes Wild's no-exec worker separately. The whole-only arm waits for any orphaned children, has a single inherited event and performs no ptrace. The local calibration recorded an original double exit when the tracer also adopted an orphan. Its corrected native replay closed every process exactly once. The devbox PMU returned zero for a real positive calibration workload. No local counts are used.

The hardware gate verifies 28 whole-tree loop observations and eight nested observations with zero and two known positive iteration counts. The nested native fixture has concurrent compiler siblings, real `exec` lineage, a fork-only Wild worker with two threads, a fast child, a signalled child and an unselected sibling. Every original event must yield its three 64-bit words, a positive instruction count and identical enabled/running durations. Each hosted worker retains the original counts, attribute bytes, argv, kernel ledgers, typed output, image hashes, stdout, stderr, boot identity and build-input receipts. A failed admission preserves its raw files and supplies no compiler share.

Attribution subtracts each complete cc tree from its inclusive rustc only once. Wild is already inside that cc tree. The separate edited `annotate_snippets` library compile stays outside the removable work. The verifier reports each worker independently, including its plain whole and traced whole, both denominator sensitivity values, saved frontend upper bound, remaining native and other instructions, and the first-repeat, edit and edit-plus-first ceilings. An invalid earlier `libutil.so` already made this same signed workflow fail using real Wild. `local-source-calibration.json` binds the earlier observed safety result and the unchanged source, using physical GNU worker opens of the provider. This experiment makes no change to the compiler or linker. [Original observer](https://github.com/astral-experiments/ohm/tree/77e33ee7781b8d823dc7f046d3bd9bea43818bc8/scripts/strict-unicode-cost)

With each complete Actions ZIP extracted to its own directory, the following command reads its original receipts and checks that the two workers had different boot IDs.

```sh
cd scripts/gnu-example-ceiling
sha256sum --strict --check SHA256SUMS
python3 -IB verify.py /path/to/worker-01 /path/to/worker-02
```
